🐧 Linux Commands

Guia completo para uso e estudo

📁 Navegação e Arquivos

pwd                # mostra o diretório atual
ls                 # lista arquivos
ls -l              # lista detalhada
ls -a              # inclui ocultos
cd pasta           # entra no diretório
cd ..              # volta um nível
cd ~               # vai para a home
tree               # estrutura em árvore

cp arquivo destino # copia arquivo
mv arquivo destino # move ou renomeia
rm arquivo         # remove arquivo
rm -r pasta        # remove pasta
mkdir pasta       # cria diretório
rmdir pasta       # remove diretório vazio
touch arquivo     # cria arquivo vazio

🔍 Busca e Localização

find / -name arquivo.txt   # busca arquivo
locate arquivo.txt          # busca rápida
grep "texto" arquivo        # busca dentro do arquivo
grep -r "texto" .           # busca recursiva
which comando              # caminho do comando
whereis comando            # localização do binário

📄 Visualização de Arquivos

cat arquivo        # exibe conteúdo
less arquivo       # leitura paginada
more arquivo       # leitura simples
head -n 10 arquivo # primeiras linhas
tail -n 10 arquivo # últimas linhas
tail -f log.txt    # acompanha log em tempo real

📦 Gerenciamento de Pacotes (APT)

sudo apt update        # atualiza lista de pacotes
sudo apt upgrade       # atualiza sistema
sudo apt install pacote# instala pacote
sudo apt remove pacote # remove pacote
sudo apt purge pacote  # remove + configs
sudo apt autoremove    # remove dependências
apt search nome        # busca pacote
apt show pacote        # detalhes

👤 Usuários e Permissões

whoami                  # usuário atual
id                      # info do usuário
adduser nome            # criar usuário
deluser nome            # remove usuário
passwd                  # remove usuário
chmod 755 arquivo       # altera permissão
chown user:grupo arquivo# altera dono

🔐 Permissões (numérico)

7 = leitura + escrita + execução  
6 = leitura + escrita  
5 = leitura + execução  
4 = leitura  

Exemplo:
chmod 755 script.sh

⚙️ Processos e Sistema

top   		    # monitora processos
htop		      # versão melhorada
ps aux       # lista processos
kill PID	    # mata processo
kill -9 PID	# força encerramento
uptime       # tempo ligado
free -h      # uso de memória
df -h        # espaço em disco
du -sh pasta # tamanho da pasta

🌐 Rede

ping google.com# testa conexão
ifconfig       # info de rede (antigo)
ip a           # IP atual (moderno)
netstat -tuln  # portas abertas
ss -tuln       # substituto do netstat
curl site.com  # requisição web
wget url       # baixar arquivo

📦 Compactação

tar -cvf arquivo.tar pasta     # cria tar
tar -xvf arquivo.tar           # extrai tar
tar -czvf arquivo.tar.gz pasta # compacta gzip
tar -xzvf arquivo.tar.gz       # extrai gzip
zip -r arquivo.zip pasta
unzip arquivo.zip

💽 Disco e Sistema

lsblk      # lista discos
mount      # monta disco
umount	    # desmonta
fdisk -l	  # partições

🕒 Data e Hora

date        # data atual
cal	       # calendário
timedatectl # configura hora

⌨️ Histórico e Atalhos

history	# comandos usados
clear	  # limpa terminal
!!	      # repete último comando
!n        # executa comando número n

🔀 Redirecionamento e Pipes

comando > arquivo    	# salva saída
comando >> arquivo    	# adiciona saída
comando < arquivo    	# entrada
comando1 | comando2   	# pipe

🧠 Variáveis e Shell

echo $HOME  		   # mostra variável
export VAR=valor  # cria variável
env	             # lista variáveis

🚀 Permissão de execução

chmod +x script.sh
./script.sh

🔄 Serviços (systemd)

systemctl start serviço
systemctl stop serviço
systemctl restart serviço
systemctl status serviço
systemctl enable serviço
systemctl disable serviço

📚 Dicas essenciais

man comando      # manual completo
comando --help  	# ajuda rápida
